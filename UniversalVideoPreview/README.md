UNIVERSAL VIDEO PREVIEW

Standalone Manifest V3 Chrome extension. Automatically plays muted previews for visible HTML5 video elements and image thumbnails linking directly to MP4/WebM/OGG video files.

INSTALL
1. Open chrome://extensions.
2. Enable Developer mode.
3. Select Load unpacked.
4. Choose C:\Users\Administrator\Desktop\RealtimeSTTTest\GEMINIDICTATE\UniversalVideoPreview
5. Reload any page already open, then use the extension button to start or stop previews.

LIMITS
- Maximum 12 simultaneous visible previews.
- Muted playback is required by most browsers for autoplay.
- A source must be exposed as a standard HTML5 video or a direct video-file link. Protected streams, blob-backed players, canvas-rendered players, and thumbnails whose video URL is hidden in site-specific JavaScript may not be detectable yet.
- Isolated from GEMINIDICTATE; no application files are modified.
